# Písma kníh

Súbory `.woff2` (podmnožiny latin a latin-ext) sú prevzaté z balíkov `@fontsource/*` 5.x.
Všetky písma sú pod licenciou SIL Open Font License 1.1 – smú sa vkladať do PDF a tlačiť.

| Písmo | Použitie |
|---|---|
| Literata | pár „classic“ |
| Fredoka + Nunito | pár „storybook“ |
| Baloo 2 + Nunito | pár „playful“ |
| Andika | pár „reader“ (prvé čítanie) |
| Patrick Hand | „písané“ obkresľovanie mena – PLACEHOLDER za školské písmo krajiny |

`@font-face` pravidlá sú v `src/features/book/styles/fonts.css`.
